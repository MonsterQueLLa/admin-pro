# Admin Pro 后台管理系统 - 需求规格说明书

---

## 1. 项目概述

### 1.1 项目背景
随着业务数据增长，需要一套统一的后台管理系统来管理各类业务数据。系统采用模块化设计，首个版本实现基础的 RBAC 权限管理和图片管理功能，后续可快速扩展其他业务模块。

### 1.2 项目目标
- 建立统一的用户认证与权限管理体系
- 实现图片资源的上传、管理、浏览功能
- 提供可扩展的模块化架构，支持后续功能迭代
- 打造专业、美观、易用的管理界面

### 1.3 术语定义

| 术语 | 说明 |
|------|------|
| RBAC | 基于角色的访问控制（Role-Based Access Control）|
| JWT | JSON Web Token，用于用户认证 |
| 动态路由 | 根据用户权限动态生成的菜单路由 |
| 数据权限 | 控制用户可查看的数据范围 |

## 2. 用户角色

### 2.1 角色定义

| 角色 | 权限范围 | 说明 |
|------|---------|------|
| 超级管理员 | 全部权限 | 系统初始化账号，拥有所有功能权限 |
| 系统管理员 | 系统管理模块 | 管理用户、角色、菜单等系统配置 |
| 内容管理员 | 图片管理模块 | 负责图片上传、编辑、分类管理 |
| 普通用户 | 查看权限 | 仅可浏览有权限的数据 |

### 2.2 角色权限矩阵

| 功能模块 | 超级管理员 | 系统管理员 | 内容管理员 | 普通用户 |
|---------|-----------|-----------|-----------|---------|

| 菜单管理 | ✓ | ✓ | ✗ | ✗ |
| 图片查看 | ✓ | ✓ | ✓ | ✓ |

#### 3.1.1 登录认证

**功能描述**：用户通过用户名密码登录系统，获取访问令牌。

**用户故事**：
- 作为用户，我希望输入用户名密码登录系统，以便访问管理功能
- 作为用户，我希望系统记住我的登录状态，避免频繁输入密码
- 作为管理员，我希望查看用户的登录记录，以便审计

**业务流程**：
```
用户打开登录页 → 输入用户名密码 → 系统验证 → 验证成功 → 跳转首页
                                    ↓ 验证失败

```

|------|------|--------|------|
| AUTH-001 | 用户登录 | P0 | 用户名密码验证，返回 JWT Token |
| AUTH-002 | 登录状态保持 | P1 | Token 有效期 7 天，支持自动续期 |
| AUTH-003 | 退出登录 | P0 | 清除本地 Token，跳转登录页 |
| AUTH-004 | 登录日志 | P2 | 记录登录时间、IP 地址 |

## 4. 非功能需求

### 4.1 性能需求

| 指标 | 要求 | 说明 |
|------|------|------|
| 首屏加载时间 | < 2s | 首页首次加载完成时间 |
| 页面切换响应 | < 300ms | 路由切换动画流畅 |
| 图片预览加载 | < 500ms | 缩略图加载时间 |
| 列表查询响应 | < 500ms | 1000 条数据内查询 |
| 并发用户数 | 50+ | 同时在线用户 |
